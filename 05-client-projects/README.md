# Execution and delivery

هر سفارش برنده یک پوشه `JOB-YYYY-NNN/` با `brief.md`, `scope.md`, `plan.md`, `activity.md`, `deliverables.md`, `qa.md`, `closure.md` دارد. لینک به OPP و شواهد تأیید مشتری الزامی است.

ثبت دقیق زمان، تصمیم‌ها، نرم‌افزار/نسخه و منبع نصب، مسئله، راه‌حل، فایل تحویلی، تست، اصلاحات، تأیید نهایی، هزینه و صورت‌حساب بدون انتشار نام و اطلاعات محرمانه مشتری.

مالکیت کد و دارایی مشتری رعایت شود؛ فایل خصوصی، قرارداد، پیام/ایمیل کامل و خروجی تجاری فقط در محل مورد تأیید کاربر/مشتری ذخیره شود؛ اینجا شناسه و خلاصهٔ غیرحساس.
