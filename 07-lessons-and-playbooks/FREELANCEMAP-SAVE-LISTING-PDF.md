# How to preserve one freelancermap project listing as readable PDF

**Scope:** Chrome desktop, from user's logged-in freelancermap account. **Recorded:** 2026-10-23. **Status:** documented instructions only; no PDF exported/received yet.

## Safe workflow
1. In Find projects, right-click **the project's title** → **Open link in new tab** (or open normally if new-tab option missing). Do not click Apply, Upgrade, or messages.
2. On the actual project detail page, expand **Show more / Read more** if present. Wait for the complete content to load.
3. Press **Ctrl + P** (Chrome Print). Set **Destination: Save as PDF**, **Pages: All**. Portrait unless landscape produces a clearer result; optionally enable Background graphics under More settings.
4. Preview the pages to ensure listing title, responsibilities, requirements, project length, compensation and employer sections are present. Some dynamic/collapsed content may not print correctly.
5. Click **Save** to Downloads; rename descriptively, e.g. `Freelancermap-Project-01.pdf` or better, with **verified** project ID when detail URL displays one. No fabricated ID. Do not include user name, private account info or client-private messages in exported content.
6. Send the PDF file as a ChatGPT attachment and also copy the project's **public permalink** from Chrome address bar: **Ctrl + L**, then **Ctrl + C**. If the PDF is truncated, supplement with screenshots or copied non-private text.
7. After user uploads, assistant analyzes exact requirements vs demonstrated skills, time estimates, tech stack and deliverables, country/language gate, budget and payment risk; creates a **genuine OPP record only after confirming listing URL/ID**, drafts proposal only on user's choice. External submission always requires explicit approval.

## Alternative
If Chrome print preview is blank or missing details, send the public URL (so the assistant can attempt independent retrieval), plus screenshots of the fully expanded description. For highly dynamic pages, a sanitized textual capture can be more complete than a PDF.
