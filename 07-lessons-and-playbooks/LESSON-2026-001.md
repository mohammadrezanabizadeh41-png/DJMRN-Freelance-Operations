# LESSON-2026-001 — Search-card start date is not contract duration

**Status:** TESTED_ON_ONE_REAL_LISTING / contextual evidence, not universal site guarantee
**Observed:** 2026-10-23 · **Site:** freelancermap · **Case:** [OPP-20261023-002](../04-opportunities/OPP-20261023-002.md) · **Listing #3064524**.
**Scenario:** looking for finite, one-time freelance deliverable projects; title-only card had `Freelance`, `100% remote`, `10/2026` but **no explicit duration**.
**What verified PDF (2 pages) showed:** `Laufzeit: 6 Monate (mit Option auf Verlängerung)`, `Vollzeit`, `hauptsächlich remote`, German minimum C1 and technical master's requirement.
**Reusable practice:** Never treat `10/2026` as 10 months or `Freelance` as a fixed deliverable; it is a date/start marker. If duration is missing from results card, check the full text **only if the title otherwise warrants it**, and always validate `Laufzeit`, `Auslastung` and site-location contradictions before approving an application.
**When NOT to generalize:** not all cards conceal long contracts and not all full descriptions use these German field names. No assertion of site-wide frequency.
**Evidence:** Original user PDF filename in [OPP record](../04-opportunities/OPP-20261023-002.md), SHA256 there. PDF file was not transferred to repository; case findings cited by document page number.
**Confidence:** Directly observed in one screenshot/PDF pair.
**Outcome:** Rejected 6-month role without spending limited free application slots; no real project was performed or won.
