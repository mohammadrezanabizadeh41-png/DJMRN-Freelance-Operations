# تجربه‌های عملی و SOP

برای هر تجربه `LESSON-YYYY-NNN.md`: مسئله/سایت/پروژه، اتفاق واقعی، عامل احتمالی (فکت جدا از فرض)، اقدام انجام‌شده، شاهد نتیجه، راه تکرار یا عدم تکرار، تاریخ، جایگزین ساده و ارتباط با پروندهٔ پروژه.

تجربهٔ منفی نیز ثبت شود (اعتبار پولی، رد پروفایل، آگهی نامناسب، محدودیت کشور، هدررفت زمان). آزمون ناموفق را به راهنمای قطعی تبدیل نکن.
