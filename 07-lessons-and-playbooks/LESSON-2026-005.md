# LESSON-2026-005 — AI SaaS video preproduction must be preceded by evidence-mapped product research

**Status:** TESTED for public-site extraction and documentary claim reconciliation; real product QA and campaign outcomes NOT TESTED.
**Date:** 2026-10-23 · Europe/Berlin
**Case:** [Orsola AI pre-award product study](../04-opportunities/pre-award-product-studies/orsola-ai-2026-10-23/README.md) / ORSOLA-001.
**Trigger:** third-party website suggested as an object of a possible one-off promotional video; not a signed commission.
**Actual observation:** 410 URLs discovered at first mapping over 4 localized paths; 103 English pages crawled; 25 apparent crawl 404 responses and a later individually recovered page; conflicts in official download, credits and connected-account help pages.
**Generalizable practice:**
1. Confirm job status first: referral/research != won client project; never invent JOB/invoice/revenue.
2. Tool need → existing tools → sitemap/map → one base-language crawl → official legal/help/pricing cross-check; avoid redundant localization copies.
3. Store original URLs, observation date, vendor claims, assistant judgment, uncertainty and contradiction distinctly.
4. Pick a single limited scenario with demonstrable visual proof; don't promise speed/security/reliability claims without evidence.
5. Require brand authorization, safe synthetic demo data and real UX test before product footage and finished script.
6. Record a brief, risk matrix, actual results and the next gate in the existing freelance GitHub authority; do not create a new project database or speculative agent.
**Why:** observed multilingual duplication inflated link counts; a crawler 404 did not prove broken page; documentation was inconsistent in feature entitlement and availability. The cause of crawler error is UNKNOWN, not a verified website fault.
**Where reusable:** software/site product briefing for one-off ads and demos using public sources. **Not reusable as:** internal code audit, production acceptance test, legal compliance certification or permission to use private client assets.
**Tools:** connected Firecrawl + web source cross-check; no new install/payment.
**Result:** documented marketing-readiness packet; NO video delivered/paid, no product login, no contract or performance benchmark.
**Linked event:** [ORSOLA session](../08-operations-and-continuity/sessions/ORSOLA-SESSION-001.md).
**Recheck:** market/terms, plan pricing, app release and product-owner claims on campaign day; inspect real UI if filming.

## 2026-10-23 Global-funnel extension — reusable lesson

- **Reusable boundary:** distinguish **creative geography** (can be globally legible) from **market/service/checkout eligibility** (must be independently verified per country) and from **commercial launch approval**. Multi-language source pages do not establish legal availability worldwide.
- **One visual is not one funnel:** a 20s brand introduction, website teaser, signup tutorial, activation proof and paid plan comparison have distinct CTA/measurement/claims gates. Reuse a master visual base, not an unadapted voiceover over all objectives.
- **Source conflict:** latest Terms web and Firecrawl retrieval returned empty JS shell, while archived extracted legal text limited offering to US/Canada. Missing new text is NOT proof the restriction was removed.
