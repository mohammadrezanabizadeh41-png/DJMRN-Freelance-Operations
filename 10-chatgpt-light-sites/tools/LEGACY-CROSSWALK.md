## Scope and selection notes
- Selected **M02** stack: existing Bridgerator MCP → Node/npm → HTML/CSS/JS, optionally the local verified Vite archive after approval. Does **not** require ArchiveBox, Blender, RenderDoc, Goose, or another agent.
- Advanced browser research tools in B remain **only** for specifically justified audits of our site or licensed reference content, and under applicable terms; not a reason to archive/copy an entire third-party website.
- Audio/video and imagery tools in D/F serve local asset production/optimization when needed; choose one tool per step; privacy/licensing.
- For WYSIWYG site editing, Onlook/Webstudio/GrapesJS/Puck are *alternatives* to direct code; their cost/license/install and ability to expose controls to this ChatGPT have not been verified.
- All 11 old C category 3D/GPU items are deliberately excluded from light-site registry. Their names remain above to show deliberate triage without making this project a duplicate of Codex.
- The archive has some downloaded tools but is NOT a software installation list: only a verified binary/version and smoke test can establish usable setup. No cloud credits, MCP account connections or public deployment initiated.

## Required further checks only when choosing a tool
Official LICENSE and package hash; documented transport and authenticated handshake if MCP; read/write permissions, cost/free quota/overage, hosting rights, available RAM on the Windows laptop, rollback and one small useful output. **Unknown cost -> STOP.**
