## 1. Six campaigns as independent professional advertising briefs

### G1 — Brand recognition and worldwide understandable introduction / P-A
**One primary action:** viewer remembers **Orsola** as a personal & professional AI assistant and discovers `orsola.ai`.
**Main human problem:** ordinary work/life is split between messages, calendar and reminders. Show both personal and business people, never merely job titles. Suitable for a global identity *concept*, without falsely promising every territory can subscribe.
**Narratives:** S07 Three Apps, One Thought; S01 Monday, Without the Mental Load; H01 One task/too many tabs, H05 Busy isn't a job title, H10 Monday mornings/client deadlines; original P-A v1 is a six-shot 20s detailed storyboard.
**Creative techniques:** M02 cinematic brand world, M03 kinetic typography, M05 before/after, M06 transitions, M07 2.5D, M13 hook variants, M15 sound-on/off.
**Assets:** B-001…B-005 logo/marks; B-010 public poster; S-001 homepage screenshot only if needed; PA01 human/worklife background; abstract original task cards; EN VO; editable end-card. Source brand baseline selected by user.
**Candidate copy:** “Work. Life. And everything in between.” / “Less Switching. More Living.” / “Explore Orsola.” No numeric time reduction.
**Formats:** primary 20s 16:9; 9:16 recast as needed; optional separate 6s bumper; NOT a demand to produce all versions.
**Key dependencies:** OR-ACT-025, 026, 027, 006, 047; next media generation separately approved.
**Status:** TEXTUAL_STORYBOARD_v1; NO STILL/VIDEO.

### G2 — Website/features discovery / P-B
**One primary action:** motivated user opens verified `https://www.orsola.ai/en/features` (or brand-confirmed landing URL).
**Human question:** “What can this actually help with?” Show flexible areas: inbox, calendar, files, meetings, reminders, work-life routines; avoid dumping all 13 core feature claims into a short film.
**Narratives:** S04 first job, S06 document search, S08 voice input, S07 generic cross-tool explanation; H02 calendar/day, H06 talk not a dozen settings.
**Creative techniques:** M01 problem/solution/CTA, M04 public site UI motion, M07 floating layered elements, M10 annotated features, M14 screen-to-world.
**Assets:** S-001 homepage, S-002 Features, S-004 About, S-005 Security optionally; B-001…B-005 exact brand. Use clean *actual public webpage captures* for public site, conceptual elements labeled.
**Draft deliverable:** 25s teaser EN VO + strong Features URL end-card; candidate vertical alternate.
**Risk:** publicly documented features ≠ proof a logged-in user completed them. No fabricated product app UI.
**Dependencies:** OR-ACT-005, 016/017, 036, 041, 047.
**Status:** OUTLINE_DRAFT / NO CAPTURES OR VIDEO.

### G3 — New eligible account registrations / P-C
**One primary action:** complete valid sign-up. Global creative *story* allowed, but specific country service/signup availability must be verified.
**Human problem:** software looks intimidating; what first step is easiest? Use a true guided onboarding, not a fictitious 1-click-to-done.

**CTA:** “Start Free” only if verified **target country and actual offer**; “Explore Orsola” when drafting general global concept.
**Formats:** one guided 20s or 30s EN demo after owner checks, possible 9:16.
**Risks:** Terms earlier US/Canada residence offer; blank retrieval of later Terms does not remove it; native app Download Coming soon; beta pricing change; user must approve promo text.
**Dependencies:** OR-ACT-008, 009, 010, 037, 044.
**Status:** DRAFT_CONCEPT / ACTUAL SIGNUP PROMISE GATED.

### G4 — First meaningful user activation / P-D
**One primary action:** the first correct useful task, e.g. a sample client email -> check calendar -> prepare reply -> human review.
**Human problem:** how does AI do more than just answer questions? Cross-tool action, but never imply safe action completed if merely drafted.
**Narratives:** S02 One Message Next Steps, S09 After the Meeting, S11 Plans Change, H04 Email.Calendar.Reply.What if one conversation?
**Creative techniques:** M04 authentic screen walkthrough, M09 one task storytelling, M10 annotation, M14 human-life + real UI.
**Assets:** S-008 least-privilege OAuth/capability view; S-009 fictional email/calendar; S-010 actual Orsola chat/draft/review; optionally S-006 docs index. These are **not** in GitHub and must not be taken from real personal account.
**Formats:** 35–45s 16:9 actual product demo, optional 15s vertical excerpt after result verified; EN VO.
**Metric if run:** actual first verified workflow completion, not vague sign-in.
**Test conditions:** permission denial, ambiguous recipient, busy calendar, insufficient credits, no unintended send, truthful error handling.
**Dependencies:** OR-ACT-008, 020 if competitor claims, 031, 038, 057. Separate authorization for account/integrations.
**Status:** PRODUCT_RUNTIME_UNVERIFIED.

### G5 — Paid-plan value / P-E
**One primary action:** understand plan choice, and only where appropriate purchase valid subscription.
**Human problem:** many specialist tools and recurring fees create uncertainty; which capability and credits serve their *actual needs*?
**Narratives:** S12 Price of Too Many Tools; H12 Before adding another app, see what one assistant connects; N08 objective plan/value explanatory structure.
**Creative techniques:** M11 feature/tier comparison, M12 sourced infographics, M10 plans explainer, M13 hook/offer.
**Assets:** S-003 public current pricing snapshot; S-011 Pro/custom-agent demo; S-012 accurate authorized checkout entitlement (private). Editable table/cards; **never model-render monetary figures**.
**CTA:** “Compare Plans” for concept; “Subscribe” only when market, real entitlement, pricing and checkout are verified.
**Price fairness:** equal workload + real credits, account count, overage, subscription currency, voice/phone charges, human setup time. No “cheapest,” “replaces all apps,” “save X%” until measured.
**Dependencies:** OR-ACT-009, 010, 020, 021, 032, 039.
**Status:** VALUE_HYPOTHESIS / TRANSACTION_NOT_TESTED.

### G6 — Returning users, trust and habitual useful tasks / P-F
**One primary action:** schedule or use a second relevant and repeatable task after first use.
**Human problem:** reminders and follow-ups can be forgotten, not everyone has time to configure complex workflows.
**Narratives:** S01 Monday weekly digest, S10 Friday Follow-Up, S03 Parent's Thursday (no medical promises), H03 sentence/reminder, H09 weekly planning.
**Creative techniques:** M09 one-task, M10 tutorial, M16 accurate locale adaptation, M15 subtitles.
**Assets:** S-013 scheduled reminder setup/result; dummy prompts; real date/time/timezone; official Task docs; B-001/B-005 logo.
**Formats:** 20s recurring helpful habit EN; additional locale only after verified support.
**Risks:** historical docs say maximum 50 scheduled tasks, 6 executions/hour, credit use and time zone; no claim it always executes safely while offline/no user review.
**Dependencies:** OR-ACT-008, 029, 040, 044, 060 for actual impact.
**Status:** CONCEPT_ONLY / RECURRING_EXECUTION_NOT_VERIFIED.

## 2. The NEW additional emotional/functional creative line L-SIMPLE-001

**Not a replacement for any of six goals.** In *every* goal, we may draw from:
- **X1 One conversation:** user says what they want in ordinary language, with permissioned connections;
- **X2 Lower cognitive setup:** illustrate fewer manual transitions as a qualitative idea; **don't claim zero configuration**;
- **X3 Voice-first:** plausible voice prompt → planned action, gated by actual microphone/credits;
- **X4 Follow-through:** planned tasks, timed reminders and follow-up;
- **X5 Work + life:** family planning, school, student, freelancer, solo operator, professional;
- **X6 Potential value vs app-stack:** honest *same-task* comparison to specialist tools if later independently tested.

**What users should feel, not necessarily a quoted claim:** “I can ask without being an automation expert; the assistant can help connect parts of my workday, and I remain involved when action needs review.” This is distinct from telling people it literally does every step without setup, judgment or any extra fee.

**Positioning vs competitive map:** Lindy and Zapier offer cross-tool agents/automation, Motion and Reclaim schedule, Fyxer handles email/meetings, Calendly handles appointment booking. We may truthfully show Orsola's documented *combination as one person's story*, not assert uniqueness, superiority or lower cost without measurement.

## 5. Campaign-level source/shot/claim tracking rule

For each actual scene create a record:
`GOAL_ID, PILOT_ID, SHOT_ID, SCENARIO_ID, HOOK_ID, METHOD_ID, BRAND_IDS, SCREEN_IDS, CLAIM_EXACT_TEXT, CLAIM_EVIDENCE_URL, EVIDENCE_DATE, MOCKUP_OR_REAL_UI, COUNTRY_SCOPE, VO_FILENAME, PROMPT_FILENAME, TOOL_MODEL_VERSION, OUTPUT_FILENAME, COST_QUOTE, ACTUAL_SPEND, USER_APPROVAL, QA_STATUS, REVISION_ID.`

The sequence must be **`GOAL -> PERSONA -> TRUTHFUL CLAIM -> EVIDENCE -> SCRIPT -> FRAMES -> PROMPT -> OUTPUT -> EDIT -> FACT CHECK -> USER/BRAND REVIEW`**. Never choose a fake plausible generated app scene as proof first and retroactively search for justification.
