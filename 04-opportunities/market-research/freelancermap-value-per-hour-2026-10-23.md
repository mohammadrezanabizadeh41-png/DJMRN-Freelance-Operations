## Business criterion: realized return on time
`expected_effective_hourly_return = (actually collectible agreed fee − platform/payment costs − license/subcontract outlay) / (search + proposal + client communication + execution + testing + revisions + handover hours)`.
**No numeric expected rates are computed here**: probability of selection, delivery effort, legal/payment access, change requests and costs are not known. Size of advertised budget is not sufficient. Need realistic scope, capped revisions, milestone payment, asset readiness, demonstrable experience and clear remote/contract rules.

## Decision: prioritized independent search batches — using actual visible 2026-10-21 UI

### Global baseline, one-time step (USER has not yet confirmed toggled)
1. `Workplace → Remote` checked (not `Hybrid`).
2. `Contract type → Freelance` checked (not `Agency contract` or `Permanent`).
3. `Worldwide` + `Newest` stay selected. Initial screenshot also excluded German-speaking countries. **Leave as is for baseline**; revisit exclusion in secondary pass since German client origin does not prove German-language requirement. Conversely Remote ≠ universally eligible.
4. `Publication date`: start last **7 days** only if site slider behaves as intended, then widen to 14–30 days if results scarce. Actual slider UI effect not verified; record chip/result count after change.
5. For **each batch**, type a *single* keyword in the main input `Search by job title, skills, or company` and press `Find projects`; record observed result count, literal keyword, filter state and at least relevant listing titles/permalinks. Do not combine all keywords into one OR assumption. When site interprets unexpected variants, use one simpler keyword. Saved daily alert NOT to be overwritten.

### Priority search sequence
- **Batch 01 (fastest ready-skill route):** `WordPress`, then `WooCommerce`. Also `Elementor`, `WordPress maintenance` or `website migration` as follow-ups if counts allow. Favor bounded repair, optimization, landing page or clear fixed-store projects. Avoid 100% custom enterprise builds without demonstrated coding proofs.
- **Batch 02 (AI evaluation):** `LLM evaluator`, then `AI trainer` or `AI evaluation`. Seek transparent per-hour/per-task rate, confirmed work volume and sample-test terms.
- **Batch 03 (content/video):** `AI video`, `video editing`, `Canva`; optionally `e-learning` or `screencast`. Prioritize ready assets, defined clip count, acceptable file formats and revision cap.
- **Batch 04 (advanced conditional):** `Python automation`, `API integration`, `n8n`; filter senior/hybrid/German-only requirements and require reproducible prior examples before proposal.
- **Batch 05 (low initial market volume):** `Excel`, `accounting`, `voice over`, `research`; worthwhile opportunistic searches, but the site's screenshot Professional fields already displayed small writing (9) and finance (23) facet counts, which cannot be used as probabilities or site-wide market stats.

### Optional professional-field filter (test ONE AT A TIME after baseline)
`Web and software development` for WP/Python; `Graphic design and Creative services` for design/video; `Digital Marketing` for content; `Writing and translation services` for writing; `Finance and Accounting` for accounting. Do not check all simultaneously and assume site's OR/AND behavior is known. Each selected facet may exclude suitable adjacent projects, e.g., AI trainer filed under IT. First run keyword alone, then compare.

### Shortlisting / spend one Basic application only if
- Fits portfolio + deliverable realistically and no fake claims.
- True 100% remote without hidden onsite visit; contract type Freelance; residency/identity truthful and allowed; payment lawful and feasible.
- Requested language mastered, deadline feasible, cost to apply/free-quota verified; employer and scope credible.
- For fixed price: deliverable list, source assets, change-request/revision limit, acceptance, handover and milestone payment must be specified.
- For hourly: hourly rate, minimum billable volume, tracking/approval and payout date clarified.
- Choose 1–3 well-qualified offers at a time; don't treat every search-result budget as guaranteed pay.
