# Opportunity pipeline (real work, not hypothetical)

هر آگهی معتبر یک شناسه `OPP-YYYYMMDD-NNN` دارد و پس از مشاهده ثبت می‌شود. برای هر رکورد: پلتفرم و URL دقیق آگهی، تاریخ انتشار و مشاهده، مبلغ و ارز، محدودهٔ کار، کشور مجاز، مهارت لازم، مهلت، ریسک، دلیل تناسب، شواهد، تصمیم و قدم بعدی.

حالت‌ها: DISCOVERED → SCREENED → DRAFTED → APPROVED_TO_SEND → SUBMITTED → REPLIED/NEGOTIATING → WON/LOST/CLOSED. حالت WON فقط با پذیرش/قرارداد واقعی، نه صرف ارسال پیشنهاد.

نمونه: `templates/OPPORTUNITY.md`؛ **هیچ فرصت واقعی بدون شواهد جعل نشده است**. فایل‌های فردی بعد از اولین پروژه در همین شاخه با شناسه ساخته شوند.
