# Accounts ≠ Applications ≠ Contracts

مرجع صف هفت‌گانه: https://app.notion.com/p/400c8c6846908125ae1ee0bd4a9625d4.

مجموع ۷ مورد: ۴ خارجی و ۳ ایرانی. در گزارش ۲۱ اکتبر **هیچ پیشنهاد، قرارداد یا پرداخت تأییدشده‌ای گزارش نشده**؛ این بدان معنا نیست که کار در کل زندگی انجام نشده است.

برای هر سایت ۵ حالت جدا ثبت کن: Account, Profile/Moderation, AbilityToApply, LegalPayout, Alerts. وضعیت هر کدام UNKNOWN تا شاهد. Login یا انتخاب USDT اثبات امکان دریافت قانونی وجه نیست.

روش استاندارد: ورود و پروفایل → آزمون واقعی آگهی و محدودیت کشور → هزینهٔ درخواست/قانون → ارزیابی حداقل ۳ آگهی → پیش‌نویس پیشنهاد → تأیید انسان → ثبت شناسه ارسال/زمان/پاسخ → قرارداد/تحویل/تسویه با شاهد. در این مخزن بدون رضایت کاربر ارسال، خرید یا تغییر حساب صورت نمی‌گیرد.
