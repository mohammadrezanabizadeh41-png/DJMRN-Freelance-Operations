## What every new chat must know
**GOAL:** create an independently authored original interactive flower-valley BACKGROUND (no header, CTA, arrows, touch pointer, sample website chrome) by combining evidence from Gladeye-like public interactive sites with original 3D/code/art. Do NOT copy vendor shader/JS/GLB/PNG/audio into public code without rights. Keep desktop mobile/screen-size behavior, camera path, pointer repulsion, scroll and dispersal/restore. The reference captured WebGL2 16 draw calls/frame with 960k *point elements*, not 960k individually identified flowers, and its GLB was camera-only. Our implementation can be smaller and visually better through original shaders and sprites.

**TOOLS ≠ SINGLE OVERLOADED PROCESS.** Acquiring a broad approved free toolbox is different from running all programs concurrently. Do **not delete an excellent tool merely for RAM concern**; choose the right tool for each independent extraction/build pass and close it afterward. Also do not treat every researched experimental browser extension as safe by default: inspect manifest, permissions, official binaries, licensing and test sandbox before activation.

## Download-only workflow (explicitly authorized in this conversation)

1. Inspect installed apps and the existing Downloads folder first: do not overwrite previous installers or assume a package is absent merely because PATH lookup fails.
2. For each candidate, verify **official upstream version and artifact for Windows x64**. Prefer portable GUI when available, Windows installer if not, signed/official source release zip for CLI/MCP when no GUI exists, and *web-only* label for browsers. Separate data sources from installable software.
3. Save only official downloadable packages under `Downloads/DJMRN-Website-Tools/{BINARY,VENDOR_BUNDLE,SOURCE_ARCHIVE}`; no extraction, execution, browser-extension activation or npm install. Downloader stores size, SHA-256 and per-item success/failure. A `.part` file is NOT completed.
4. Once downloads finish, audit actual files and hashes against official release metadata; report **DOWNLOADED, FAILED, ALREADY PRESENT, PENDING_URL, WEB_ONLY, INSTALLED_ALREADY** separately. Do not turn a queued or begun transfer into 'downloaded'.
