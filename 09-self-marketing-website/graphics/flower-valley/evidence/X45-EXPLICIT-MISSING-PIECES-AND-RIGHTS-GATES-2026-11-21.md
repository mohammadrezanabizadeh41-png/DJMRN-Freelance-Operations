## E. Failures and deterministic fallback
1. JS mismatch or imports missing → stop boot attempt, preserve trace, use ONE other coherent capture family; only then compatible module implementation.
2. External URL attempted → block egress, local resolver only; missing resource identified by exact path and SHA.
3. Camera type mismatch → log matrices and track mapping; implement adapter rather than assigning unknown original semantics.
4. GPU point shader untranslatable → keep original target behavior and create compatible independent sprite system with explicit provenance.
5. Bloom/FX too heavy → staged adaptive quality while preserving essential visual behavior.
6. Audio blocked by autoplay/rights → muted default, avoid copying music into public product, user-gesture authorized media only.
7. Old/new screenshot ambiguous → mark UNVERIFIED; do not treat archive timestamp as website-release version.
8. Unverified asset rights for release → private-only analysis, public implementation with independently authored replacements.
9. No exact renderer fidelity after repeated checks → qualify as functional recreation with named visual gaps, never assert binary-exact copy.
10. RAM <100MiB → stop, recover, record failure and resume with smaller knobs after approval, keep VPN/remote alive.
