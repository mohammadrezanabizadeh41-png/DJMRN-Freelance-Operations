# ابزارهای استفاده‌شده برای کار واقعی

هر نصب یا سرویس فقط با `real use case` قابل ثبت است. پیش از توصیه/نصب: قابلیت موجود را بررسی کن، منبع رسمی/نسخه/مجوز/قیمت و سهمیه/اجازهٔ ایران/امنیت را با تاریخ بررسی کن؛ ساده‌ترین جایگزین رایگان را مقایسه کن؛ نصب پس از مجوز کاربر. نام، نقش، پروژه مرتبط، تست و نتیجه را در `TOOL-REGISTRY.md` ثبت کن.

کتابخانه Applied DJMRN تنها کاتالوگ تحقیقاتی است؛ کشف ابزار ≠ انتخاب/فعال‌سازی. مخزن Intelligent-Assistant فقط مرتبط با ساخت دستیار است و مالک این فعالیت فریلنسری نیست.
